# NAVERA Phuket — Revenue & Cost Suite

เว็บแอปบันทึกและวิเคราะห์รายได้ ต้นทุน และสถิติรายวันของห้องอาหาร/อุปกรณ์จัดเลี้ยง (outlet) ในโรงแรม
สร้างด้วย Node.js + Express + ExcelJS — ข้อมูลทั้งหมดเก็บในไฟล์ Excel (`Revenue_Cost_Data.xlsx`) ไม่ต้องมีฐานข้อมูลแยกต่างหาก

## ฟีเจอร์หลัก

- **Data Entry** — กรอกรายได้/Cover/ต้นทุน แยกตามมื้อ (ABF, Breakfast, Lunch, Dinner, Supper) × หมวด (Food, Beverage, Wine, Other), ยอด Purchase/Store Issue, Transfer In/Out, Credit Cost แยก 4 หมวด, และสถิติห้องพัก + สภาพอากาศ
- **โหลดข้อมูลเดิมกลับมาแก้ไขได้** — เลือกวันที่ + outlet เดิม ระบบจะดึงข้อมูลที่บันทึกไว้กลับมาแสดงบนฟอร์ม
- **สำรองข้อมูลอัตโนมัติ** — ทุกครั้งที่บันทึก ระบบจะเก็บสำเนาไว้ในโฟลเดอร์ `backups/` (เก็บล่าสุด 30 ไฟล์)
- **Analytics Dashboard / Shift Analytics / Meal Analytics** — กราฟสรุปยอดตาม outlet/มื้อ/กะ
- **Top Sale F&B / Top Purchasing** — อันดับสินค้าขายดีและยอดจัดซื้อ พร้อมนำเข้าจาก Excel
- **Budget Entry / Monthly Report / Upsale** — บันทึกงบประมาณ รายงานรายเดือน และเป้า upsale
- **สิทธิ์ 2 ระดับ** — พนักงาน (ดู Dashboard อย่างเดียว) และผู้ดูแลระบบ (กรอก/แก้ไขข้อมูลได้ทุกหน้า)

## ความต้องการของระบบ

- Node.js เวอร์ชัน 18 ขึ้นไป
- (แนะนำ) ไม่มีโปรแกรมอื่นใช้พอร์ต 3500 อยู่ — ถ้าชนกันให้เปลี่ยนพอร์ตใน `.env`

## วิธีติดตั้ง

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. สร้างไฟล์ค่าตั้ง (รหัสผ่าน และพอร์ต)
#    Windows
copy .env.example .env
#    macOS / Linux
cp .env.example .env

# 3. แก้ไข .env กำหนดรหัสผ่านของตัวเอง
#    ADMIN_PASSWORD = รหัสผ่านผู้ดูแลระบบ (กรอก/แก้ข้อมูลได้)
#    STAFF_PASSWORD = รหัสผ่านพนักงาน (ดู Dashboard ได้อย่างเดียว)
#    PORT           = พอร์ตของเซิร์ฟเวอร์ (ค่าเริ่มต้น 3500)

# 4. รันเซิร์ฟเวอร์
npm start
#    หรือบน Windows ดับเบิลคลิก start-server.bat
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3500` — ครั้งแรกที่บันทึกข้อมูล ระบบจะสร้างไฟล์ `Revenue_Cost_Data.xlsx` ให้อัตโนมัติ

## โครงสร้างไฟล์สำคัญ

| ไฟล์/โฟลเดอร์ | คำอธิบาย |
|---|---|
| `server.js` | โค้ดเซิร์ฟเวอร์ทั้งหมด (API + การจัดการไฟล์ Excel) |
| `public/index.html` | หน้าเว็บฝั่ง client |
| `.env` | รหัสผ่าน/พอร์ต — **ไม่ขึ้น git** |
| `Revenue_Cost_Data.xlsx` | ฐานข้อมูลหลัก — **ไม่ขึ้น git** (สร้างอัตโนมัติ) |
| `backups/` | สำเนาสำรองอัตโนมัติ — **ไม่ขึ้น git** |
| `Template_TopSale_FnB.xlsx`, `Template_TopPurchasing.xlsx` | เทมเพลตสำหรับกรอกข้อมูลนำเข้าหน้า Top Sale / Top Purchasing |

## การใช้งานในวง LAN

เซิร์ฟเวอร์รันที่ `0.0.0.0` — เครื่องอื่นในวงเครือข่ายเดียวกันเปิด `http://<IP-ของเครื่องเซิร์ฟเวอร์>:3500` ได้เลย
(ดู IP ด้วยคำสั่ง `ipconfig` บน Windows)

## หมายเหตุ

- ระบบล็อกอินนี้เป็นการป้องกันการใช้งานพื้นฐาน ไม่ใช่ระบบรักษาความปลอดภัยระดับสูง — ควรใช้ในวงเครือข่ายภายในของโรงแรมเท่านั้น
- ถ้าเซิร์ฟเวอร์สตาร์ทแล้วเปิดเว็บไม่ได้/ข้อมูลไม่ขึ้น ให้ตรวจว่ามีโปรแกรมอื่นใช้พอร์ตเดียวกันอยู่หรือไม่ (log จะแจ้งเตือนให้)
