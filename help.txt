1. ใช้งานเฉพาะภายในองค์กร/แผนก (วง Wi-Fi หรือ LAN เดียวกัน)
วิธีนี้เหมาะที่สุดสำหรับใช้ภายในโรงแรมหรือแผนกเดียวกัน ปลอดภัยและตั้งค่าง่าย ไม่ต้องต่อเน็ตออกข้างนอก

ขั้นตอน:

เปิดโปรแกรมเซิร์ฟเวอร์ที่คุณใช้รัน Backend บนเครื่องตัวเอง (เช่น node server.js หรือ python app.py) บนพอร์ตที่กำหนด เช่น 3000 หรือ 5000

หาหมายเลข IP Address ของเครื่องคุณ:

Windows: เปิด Command Prompt แล้วพิมพ์ ipconfig (ดูที่ IPv4 Address เช่น 192.168.1.50)

Mac: เข้า System Settings > Network > Wi-Fi/Ethernet หรือเปิด Terminal พิมพ์ ifconfig

ให้เครื่องคนอื่นที่ต่อ Wi-Fi เดียวกันเปิดเบราว์เซอร์แล้วพิมพ์:

[http://192.168.1.50:3000](http://192.168.1.50:3000) (เปลี่ยนตาม IP และ Port ของคุณ)

หมายเหตุ: หากเครื่องอื่นเข้าไม่ได้ ให้ตรวจสอบการตั้งค่า Windows Firewall โดยเปิดอนุญาต (Allow) พอร์ตที่ใช้งาน

2. ต้องการให้คนภายนอกเข้าใช้งานได้ผ่านอินเทอร์เน็ต
หากต้องการส่งลิงก์ให้คนที่อยู่นอกโรงแรม/นอกบ้านเข้าใช้งานได้ มี 2 ทางเลือกหลัก:

ทางเลือก A: ใช้ Tunneling Tool เช่น Cloudflare Tunnel หรือ ngrok (แนะนำ ง่ายและปลอดภัย)
ไม่ต้องแก้เราเตอร์ ไม่ต้องตั้งค่า Forward Port และได้ URL แบบ HTTPS ทันที

ตัวอย่างใช้ ngrok:

ดาวน์โหลดและติดตั้ง ngrok

รันคำสั่งชี้ไปที่พอร์ตของเว็บคุณ เช่น:

Bash
ngrok http 3000
จะได้ลิงก์สาธารณะ (เช่น [https://xxxx.ngrok-free.app](https://xxxx.ngrok-free.app)) ส่งลิงก์นี้ให้ผู้อื่นเปิดใช้งานได้ทันที

ทางเลือก B: ตั้งค่า Port Forwarding บน Router
ต้องเข้าไปตั้งค่าที่หน้า Router ของที่พัก/สำนักงาน เพื่อ Forward พอร์ตอินเทอร์เน็ตภายนอกมายัง IP เครื่องคุณ

ต้องใช้บริการ DDNS (Dynamic DNS) เพื่อรับมือกับ IP ขาออกที่เปลี่ยนไปเรื่อยๆ

ข้อจำกัด: หากเป็นอินเทอร์เน็ตขององค์กรหรือโรงแรม มักจะติดไฟร์วอลล์และไม่สามารถตั้งค่าเราเตอร์ได้เอง

⚠️ สิ่งที่ต้องคำนึงเมื่อใช้เครื่องตัวเองเป็น Server
ต้องเปิดเครื่องไว้ตลอด: หากปิดเครื่อง โน้ตบุ๊กเข้าโหมด Sleep หรือปิดโปรแกรมเซิร์ฟเวอร์ คนอื่นจะไม่สามารถเข้าเว็บได้ทันที

ความปลอดภัย: หากเปิดต่ออินเทอร์เน็ตภายนอก ควรเปลี่ยนรหัสผ่านแอดมินให้รัดกุม และหลีกเลี่ยงการเปิดสิทธิ์การเข้าถึงโฟลเดอร์สำคัญในเครื่อง

ระบบไฟล์ Excel: เมื่อใช้เครื่องตัวเอง ข้อดีคือไฟล์ Excel จะถูกอ่านและเขียนลงในฮาร์ดดิสก์ของเครื่องคุณโดยตรง ทำให้จัดการไฟล์ต้นทางได้สะดวก
